# Study Deck

I built Study Deck with AI to revise for **IN3050** and **IN3230**. Anyone is welcome to use it. Questions draw on my notes, lectures, group exercises, course repositories, and past papers. Cant guarantee full coverage or good grades :) 

[Open Study Deck](https://knukev.github.io/Study_deck/)

## Practise

- In **Practice**, choose **Question source → Past exams** for IN3050. Select the 2024 final, 2025 final, 2025 trial, or **All past exams**, then choose the number of questions. This uses exam items, excluding generated variants and written prompts converted to multiple choice. Source errors have been clarified where needed.
- Use **Question bank → Recent exams and prep** for exam-based practice including variants and adapted written prompts.
- In **Syllabus**, choose **Practise this topic** to study one topic. Both courses have **Summary of this topic** with core concepts, a worked example, and self-check questions.

- In **Key terms**, search short definitions for both courses, filter by course or topic, and sort A–Z or by topic.

## Create and share decks

1. In **My decks**, select **Create deck**. Add questions and answers, mark the correct options, and save.
2. Select **Export JSON** to download a copy of a deck.
3. Select **Import JSON** and choose the file to open the deck in another browser or on another device.

Decks and results are stored in your browser. Exports contain the deck's questions and answers.

## Run locally

With Node.js 24 or later, run `npm ci` and `npm run dev`, then open [the local app](http://127.0.0.1:5174/).
