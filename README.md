# Exam Quizer

I built Exam Quizer primarily for my own exam preparation in **IN3050** and **IN3230**. Anyone who wants to try it is welcome to use it.

The questions draw on my notes, lectures, group exercises, GitHub course materials, and past exams. I built the app with AI assistance. I can't guarantee full syllabus coverage or good grades.

## Run locally

With Node.js 24 or later, run `npm ci` and `npm run dev`, then open [the local app](http://127.0.0.1:5174/).

## GitHub Pages

Select **Settings → Pages → Source → GitHub Actions**, then run **Deploy Exam Quizer** on `main`. Later pushes to `main` deploy automatically.
